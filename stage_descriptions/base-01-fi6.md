A [web application firewall](https://en.wikipedia.org/wiki/Web_application_firewall) (WAF) sits in front of a web application and checks every request on its way in. It blocks the requests that look like attacks before they reach the application. In this stage, you'll start your firewall's HTTP server on port 8080 and answer health checks with `200 OK`. A health check is a `GET /health` request that asks whether your firewall is running.
